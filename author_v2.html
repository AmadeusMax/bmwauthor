BMW Author — Guide & Features

3 Distinct Color Schemes & Paper Styles

Switch between Light (Daylight), Medium (Twilight), and Dark (Midnight) UI themes from the top bar dropdown. You can also independently customize your script paper style between Classic White, Warm Sepia, and Night Charcoal.

Toolbar & Features
  • Start Blank: Resets canvas to a clean new screenplay.
  • Load: Imports a saved script JSON file into the suite.
  • Create Menu: Insert Acts, Scenes, Action, Characters, Dialogue, Parentheticals, or Writer Notes.
  • Cover Sheet: Toggle and customize industry-standard title pages.
  • Print / PDF: Renders standard screenplay pages for hardcopy or PDF export.
Smart Keyboard Shortcuts
Enter Key Creates the next appropriate screenplay block (e.g. Character → Dialogue).
Tab Key Cycles element types (Action → Character → Parenthetical → Dialogue).
Backspace Deletes an empty block and focuses the previous element.
